# CSS-Shape-Outside

CSS `shape-outside` プロパティを活用した、Nothing OS デザイン美学に基づくレスポンシブWebページ。

## Features

- **shape-outside + clip-path 同期アニメーション**: 六角形ポリゴンの頂点座標を16フェーズで変化させ、キューブの自転を表現
- **Nothing OS Aesthetic**: 漆黒背景、Monospace/ドットマトリクスフォント、赤色アクセント、フィルムグレイン
- **ワイヤーフレーム3Dキューブ**: アイソメトリック投影された六角形シルエットをCSS polygonで再現
- **テキスト回り込み連動**: shape-outside のポリゴン変形に連動してテキストが押し出し/復帰するリアルタイム効果
- **モバイルファーストレスポンシブ**: 3段階のブレークポイント（base / 768px / 1200px）

## Tech

HTML/CSS only. No JavaScript.
