OBJ-014 / rotational study / hex-wire shell

今日の収集対象は、卓上に置かれた小型スピーカーを抽象化した立体オブジェクトである。外周はやや 鈍いシルバー、内部の空洞は黒く沈み、観察者が正面に立つと最小限の線だけが浮き上がる。見た目は 無口だが、角度を変えると各面の距離感が変わり、単純な箱にはない緊張が生まれる。その印象を Web上で再構築するため、このページでは右上のワイヤーフレームを回転させながら、文章そのものも 少しずつ押し返されるように設計している。

`shape-outside` による回り込みは、単なる飾りではなく、立体の存在感をテキストレイアウトへ直接 伝達するための仕組みである。六角形が斜め上から見たキューブのように幅を広げる瞬間、左側の段落は わずかに押し出され、オブジェクトが手前へ張り出したような錯覚を生む。逆に、回転により面が 細く見える局面では、文の流れは静かに右へ戻り、まるで機械が一定のリズムで呼吸しているかのような 連動感を保つ。Nothing Phone に見られる精密なハードウェア表現は、こうした控えめな変位の積み重ねに よって成立している。

背景には微細なフィルムグレインを重ね、完全な黒一色ではなく、僅かに空気を含んだ暗闇として 画面を成立させた。テキストは白と銀に限定し、視線を引き止めるポイントだけに赤いドットや細い線を 配置している。これは情報を強く叫ぶためではなく、観察の起点を静かに指し示すための赤である。 もしこのレイアウトが製品の取扱説明の断片やギャラリーの注釈として存在したなら、ユーザーは読むことと 見ることを連続したひとつの操作として受け取れるはずだ。

モバイルではオブジェクトを抑制したサイズに留め、画面上部の密度を保ちながら本文の可読性を優先した。 デスクトップへ拡張されると、同じ立体はより大きく、より深く干渉し、段落の輪郭そのものを造形していく。 HTML と CSS だけで構成されたこのページは、装飾よりも構造、効果よりも精度を重視し、静かな未来感を 伝えるサンプルとして組み立てられている。毎日の何気ない物体も、視点と文脈を与えれば、十分に 収集対象となりうる。その事実を示すために、ここでは一つの立体をゆっくりと自転させ続ける。
